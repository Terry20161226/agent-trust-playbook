# Agent 治理实战 Playbook

> 主线一句话：**AI 说它做完了，怎么证明它真做完了？**

本仓是「Agent 可信度工程」作品集的内容资产部分：一套基于生产环境运营 coding agent 经验沉淀的实战系列文章。卖点不是方法论本身，而是生产级素材——事故机制、门禁演化过程、可量化证据，全部以**可独立运行的合成示例**重现。
